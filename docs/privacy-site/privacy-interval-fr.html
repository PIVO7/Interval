Politique de confidentialité — Interval

Dernière mise à jour : 12 août 2026

Interval est une application de minuteur d'intervalles pour les coachs, les kinésithérapeutes et tous ceux qui s'entraînent régulièrement en mode HIIT/Tabata. Nous voulons traiter le moins de données personnelles possible, et quand nous le faisons — uniquement pour faire fonctionner l'application pour vous. Pas de tracking, pas de publicité, pas de vente de données.

Ce document décrit quelles données nous collectons, comment nous les utilisons et quels sont vos droits.

1. Qui nous sommes

Responsable du traitement des données (au sens de l'art. 4(7) du RGPD) :

Jelle Wauters
e-mail : jelle@pivo7.be

Pour toute question sur vos données, ou pour exercer vos droits (voir section 7), utilisez cette adresse e-mail.

2. Quelles données nous collectons

a. Connexion via Sign in with Apple (facultatif)

Vous pouvez utiliser Interval de manière totalement anonyme (bouton « Continuer sans compte » dans l'onboarding). Dans ce cas, nous ne stockons aucune donnée personnelle sur un serveur. Seuls vos réglages d'entraînement et vos préférences restent en local sur votre appareil.

Si vous choisissez « Sign in with Apple », nous recevons d'Apple :

  • un identifiant utilisateur anonyme (le userIdentifier d'Apple, p. ex. 001234.abcdef1234567890.0000),
  • votre nom complet — uniquement lors de la première connexion, et uniquement si vous y consentez dans la boîte de dialogue d'Apple,
  • une adresse e-mail — qui peut être votre véritable adresse ou un alias « Private Relay » généré par Apple si vous choisissez cette option dans la même boîte de dialogue.

Nous stockons ces données dans notre base de données (voir section 4) afin de pouvoir lier vos entraînements enregistrés à votre compte.

b. Entraînements enregistrés comme favoris

Lorsque vous enregistrez un schéma d'intervalles (effort / repos / nombre de rounds) comme favori, nous stockons :

  • le nom que vous donnez au schéma (p. ex. « Tabata 30/15 »),
  • la durée des phases d'effort (secondes),
  • la durée des phases de repos (secondes),
  • le nombre de rounds,
  • la date de création.

En local uniquement si vous n'êtes pas connecté. Également dans notre base de données cloud si vous êtes connecté.

c. Achat intégré (Interval Pro)

L'achat unique « Interval Pro » est entièrement géré par l'App Store d'Apple (StoreKit). Nous ne recevons aucune donnée de paiement — pas de numéros de carte, pas d'adresse de facturation, pas d'identifiant Apple. Le fait que vous ayez effectué l'achat est géré par Apple et uniquement lu en local par l'application ; nous ne le stockons pas sur notre serveur.

d. Préférences locales

Les données suivantes sont stockées uniquement en local sur votre appareil, dans les UserDefaults d'iOS, et ne sont jamais envoyées à notre serveur :

  • si vous avez déjà vu l'onboarding,
  • le dernier son d'ambiance choisi et son volume,
  • si le retour haptique et les signaux sonores sont activés,
  • si vous avez sélectionné l'apparence claire / sombre / système.

e. Ce que nous ne collectons PAS

  • Pas de localisation.
  • Pas de contacts, photos ou données de microphone.
  • Pas de données de santé (pas de fréquence cardiaque ou données similaires).
  • Pas de pixels d'analytics, pas d'identifiants publicitaires.
  • Pas de tracking entre applications ou sites web.

4. Avec qui nous partageons des données

Nous ne vendons pas vos données et ne les partageons pas avec des tiers à des fins commerciales. Nous faisons toutefois appel aux sous-traitants suivants pour le fonctionnement technique de l'application :

Supabase (base de données + authentification)

Notre backend fonctionne sur Supabase, un fournisseur PostgreSQL-as-a-service. Supabase conserve vos données de compte et vos entraînements enregistrés sur des serveurs situés dans l'Union européenne (région eu-central-1, Francfort). Supabase est le sous-traitant, nous sommes le responsable du traitement. Leur politique de confidentialité : supabase.com/privacy.

Apple

  • Sign in with Apple : Apple authentifie votre identité. Nous ne recevons que ce que vous approuvez dans la boîte de dialogue d'Apple (section 2.a).
  • App Store / StoreKit : l'achat unique Interval Pro est entièrement géré par Apple (section 2.c). Politique de confidentialité d'Apple : apple.com/legal/privacy.

Aucun autre tiers ne reçoit vos données.

6. Sécurité

  • Toute communication entre l'application et notre backend passe par HTTPS / TLS 1.2+.
  • Les tables de la base de données utilisent le Row Level Security (RLS) : vos données ne sont accessibles que depuis votre session authentifiée.
  • Nous ne touchons jamais à votre mot de passe Apple privé — Sign in with Apple utilise uniquement des jetons d'identité.

7. Vos droits

En vertu du Règlement général sur la protection des données (RGPD), vous avez le droit de :

  • demander l'accès aux données que nous détenons sur vous (art. 15),
  • demander la rectification de données incorrectes (art. 16),
  • demander l'effacement de vos données (art. 17 — « droit à l'oubli »),
  • demander la limitation du traitement (art. 18),
  • demander la portabilité de vos données — nous vous envoyons alors un fichier JSON contenant tout ce que nous détenons sur vous (art. 20),
  • vous opposer à notre traitement (art. 21),
  • déposer une plainte auprès de l'Autorité de protection des données belge (autoriteprotectiondonnees.be) ou de l'autorité de contrôle de votre propre pays de l'UE.

Envoyez un e-mail à jelle@pivo7.be et nous traiterons votre demande dans un délai de 30 jours.

Vous voulez simplement supprimer tout votre compte ? Envoyez « Supprimez mon compte » à l'adresse ci-dessus avec votre identifiant Apple ou l'adresse e-mail utilisée pour Sign in with Apple, et nous le ferons dans les 7 jours ouvrables.

8. Modifications de cette politique

Si nous modifions substantiellement cette politique (p. ex. nouveaux sous-traitants, nouvelles catégories de données), nous mettons à jour la date « Dernière mise à jour » en haut de la page et nous informons les utilisateurs connectés par e-mail. Les modifications mineures (fautes de frappe, clarifications) apparaissent simplement ici sans notification.
